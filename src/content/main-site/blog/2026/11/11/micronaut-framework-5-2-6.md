We are excited to announce the release of [Micronaut Framework 5.2.6](https://github.com/micronaut-projects/micronaut-platform/releases/tag/v5.2.6)!

**Micronaut Framework 5.2.6 is a security release.** [Micronaut Core 5.2.23](https://github.com/micronaut-projects/micronaut-core/releases/tag/v5.2.23) addresses 38 GitHub Security Advisories across HTTP servers and routing, clients, WebSockets, and static resource handling. [Micronaut Security 5.4.2](https://github.com/micronaut-projects/micronaut-security/releases/tag/v5.4.2) fixes vulnerabilities in URL authorization rules, OAuth and OpenID handling, CSRF protection, LDAP authentication, redirects, JWT validation, and token handling. **We strongly recommend that all users update to Micronaut Framework 5.2.6.**

The release also includes [Micronaut Data 5.2.5](https://github.com/micronaut-projects/micronaut-data/releases/tag/v5.2.5), which fixes repository data source selection for injection points and transaction manager selection for inherited methods.

If you are using Micronaut Framework 4, update to [Micronaut Platform 4.10.24](https://github.com/micronaut-projects/micronaut-platform/releases/tag/v4.10.24), which includes [Micronaut Core 4.10.37](https://github.com/micronaut-projects/micronaut-core/releases/tag/v4.10.37) and [Micronaut Security 4.18.2](https://github.com/micronaut-projects/micronaut-security/releases/tag/v4.18.2) with corresponding security fixes.

If you are using Micronaut Framework 3, update to [Micronaut Core 3.10.19](https://github.com/micronaut-projects/micronaut-core/releases/tag/v3.10.19). It addresses 25 GitHub Security Advisories and updates the managed [Micronaut Security version to 3.11.3](https://github.com/micronaut-projects/micronaut-security/releases/tag/v3.11.3), which includes corresponding security fixes.

If you haven’t yet updated to [Micronaut Framework 5](/2026/05/20/micronaut-framework-5-0-0-released/), this is an excellent opportunity to do so!

Please feel free to [reach out to us](/support/) if you need any assistance.
