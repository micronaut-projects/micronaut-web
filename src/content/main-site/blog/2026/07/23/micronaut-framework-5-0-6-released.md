We are excited to announce the release of Micronaut framework 5.0.6! It includes a release of [Micronaut Core](https://github.com/micronaut-projects/micronaut-core/releases/tag/v5.0.7), [Micronaut Oracle Cloud](https://github.com/micronaut-projects/micronaut-oracle-cloud/releases/tag/v6.0.2), and [Micronaut Data](https://github.com/micronaut-projects/micronaut-data/releases/tag/v5.0.6).

If you haven’t yet updated to [Micronaut Framework 5](https://micronaut.io/2026/05/20/micronaut-framework-5-0-0-released/), this is an excellent opportunity to do so!

Please feel free to [reach out to us](https://micronaut.io/support/) if you need any assistance.
