We are excited to announce the release of Micronaut framework 5.0.5! It includes a release of [Micronaut AWS](https://github.com/micronaut-projects/micronaut-aws/releases/v5.0.2), [Micronaut Core](https://github.com/micronaut-projects/micronaut-core/releases/v5.0.6), [Micronaut gRPC](https://github.com/micronaut-projects/micronaut-grpc/releases/v5.0.1), [Micronaut Oracle Cloud](https://github.com/micronaut-projects/micronaut-oracle-cloud/releases/v6.0.1), and [Micronaut Logging 2.0.1](https://github.com/micronaut-projects/micronaut-logging/releases/v2.0.1).

If you haven’t yet updated to [Micronaut Framework 5](https://micronaut.io/2026/05/20/micronaut-framework-5-0-0-released/), this is an excellent opportunity to do so!

Please feel free to [reach out to us](https://micronaut.io/support/) if you need any assistance.
