The Micronaut Foundation is excited to announce the release of [Micronaut Framework 5.1.5](https://github.com/micronaut-projects/micronaut-platform/releases/tag/v5.1.5)!

It includes [Micronaut Core 5.1.15](https://github.com/micronaut-projects/micronaut-core/releases/tag/v5.1.15), which updates managed [Netty](https://netty.io/) to 4.2.18.Final.

**We strongly recommend that users update to Micronaut Framework 5.1.5**, as [Netty 4.2.18.Final](https://netty.io/news/2026/09/09/4-2-18-Final.html) is a security release containing several security fixes.

If you are using Micronaut Framework 4, update to [Micronaut Platform 4.10.18](https://github.com/micronaut-projects/micronaut-platform/releases/tag/v4.10.18). It includes [Micronaut Core 4.10.28](https://github.com/micronaut-projects/micronaut-core/releases/tag/v4.10.28), which also updates managed Netty to 4.2.18.Final.

If you are using Micronaut Framework 3, update to [Micronaut Core 3.10.12](https://github.com/micronaut-projects/micronaut-core/releases/tag/v3.10.12), which updates managed Netty to 4.1.138.Final. [Netty 4.1](https://netty.io/news/2026/09/09/4-1-EOL-announcement.html) will reach end of life on July 1, 2027. Thus, this is a good time to update to [Micronaut Framework 5](/2026/05/20/micronaut-framework-5-0-0-released/).

Please feel free to [reach out to us](/support/) if you need any assistance.
